# Controle de Produtos PHP

Projeto introdutório desenvolvido individualmente com o objetivo de conhecer e praticar a linguagem PHP.

## Sobre o projeto

Este foi um projeto de aprendizado independente, desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas, com o propósito de explorar uma nova tecnologia e colocar em prática os conhecimentos adquiridos.

## Objetivos de aprendizado

- Ter o primeiro contato prático com PHP.
- Compreender conceitos fundamentais da linguagem.
- Desenvolver autonomia no aprendizado de novas tecnologias.
- Aplicar conhecimentos de programação na construção de um projeto.

## Tecnologia utilizada

- PHP
